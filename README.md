# Keyboard Hook Demo

A Python project exploring Windows API interaction using `ctypes`.

The project demonstrates how Python can interact with Windows APIs to retrieve information about the currently focused window.

## Features

* Windows API interaction
* Foreground window detection
* Window title retrieval
* Python `ctypes`
* Windows handles

## Requirements

* Windows
* Python 3

## Run

```bash
python keyboard_demo.py
```

## Project Structure

```text
keyboard-hook-demo/
├── keyboard_demo.py
├── .gitignore
└── README.md
```

## Notes

This project is an educational demonstration of Windows API interaction. It does not record or store keyboard input.
